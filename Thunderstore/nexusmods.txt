[font=Arial Black][color=DarkOrange][size=5][b]Weapon XP Multiplier[/b][/size][/color][/font]

A BepInEx mod for [b]SULFUR[/b] that lets you configure weapon level-up XP from 0x to 100x.

[color=RoyalBlue][b]What This Mod Does[/b][/color]

This mod adds a configurable multiplier for weapon XP.

Default value:

[code]2.0x[/code]
Examples:

[code]XpMultiplier = 0     -> no weapon XP
XpMultiplier = 0.01  -> 1% weapon XP
XpMultiplier = 0.2   -> 20% weapon XP
XpMultiplier = 1     -> vanilla weapon XP
XpMultiplier = 2     -> double weapon XP
XpMultiplier = 10.2  -> 10.2x weapon XP
XpMultiplier = 100   -> 100x weapon XP[/code]
[color=RoyalBlue][b]What It Affects[/b][/color]

This mod patches weapon XP gain through:

[code]PerfectRandom.Sulfur.Core.Weapons.Weapon.AddExperience(float)[/code]
Weapons earn XP when you kill an enemy you damaged. The multiplier is applied to that amount after the game's own bonuses (for example Library Card or Lock of the Magus), so it stacks with them.

It affects non-melee, non-throwable weapons that normally gain weapon XP.

With a high multiplier a single kill can raise a weapon by several ranks at once. The game then shows one rank-up notice, but every rank (and its enchantment slot) is still granted.

[color=RoyalBlue][b]What It Does NOT Affect[/b][/color]

This mod does not change:

[code]Player XP
Money
Loot
Enemy stats
Weapon damage
Weapon fire rate
Weapon durability
Melee weapon XP
Throwable weapon XP[/code]
[color=RoyalBlue][b]Configuration[/b][/color]

After launching the game once with the mod installed, a config file will be generated at:

[code]BepInEx/config/kumo.sulfur.weapon_xp_multiplier.cfg[/code]
Default config:

[code][General]

EnableMod = true
XpMultiplier = 2

[Debug]

LogXpChanges = false[/code]
[color=DodgerBlue][b]EnableMod[/b][/color]

[code]EnableMod = true[/code]
Set to [color=#ffff00]false[/color] to disable the mod without uninstalling it.

[color=DodgerBlue][b]XpMultiplier[/b][/color]

[code]XpMultiplier = 2[/code]
Weapon XP multiplier.

Allowed range:

[code]0 to 100[/code]
Decimal values are supported.

Use a period for decimals:

[code]XpMultiplier = 0.2
XpMultiplier = 10.2[/code]
Do not use a comma. The comma is read as a thousands separator, so this gives [b]2x[/b], not 0.2x:

[code]XpMultiplier = 0,2[/code]
Values outside 0 to 100 are clamped to the nearest limit.

[color=DodgerBlue][b]LogXpChanges[/b][/color]

[code]LogXpChanges = false[/code]
Set this to [color=#ffff00]true[/color] only for testing.

For normal gameplay, keep it set to [color=#ffff00]false[/color].

[color=RoyalBlue][b]Installation[/b][/color]

[color=DodgerBlue][b]Thunderstore / r2modman[/b][/color]

Install the mod through Thunderstore Mod Manager or r2modman.

Make sure the required BepInExPack dependency is installed.

[color=DodgerBlue][b]Manual Installation[/b][/color]

[list=1]
[*]Install BepInExPack for SULFUR.[/*]
[*]Start the game once so BepInEx creates its folders.[/*]
[*]Create the folder [color=#ffff00]BepInEx/plugins/WeaponXpMultiplier/[/color] and copy [color=#ffff00]WeaponXpMultiplier.dll[/color] and the [color=#ffff00]lang[/color] folder into it. The [color=#ffff00]lang[/color] folder is only needed for translated SULFUR Config pages.[/*]
[*]Start the game.[/*]
[*]Edit the generated config file if you want a different multiplier.[/*]
[/list]
[color=RoyalBlue][b]Compatibility[/b][/color]

Tested with SULFUR 1.0.6.

This mod should be compatible with most mods.

If another mod also changes weapon XP through [color=#ffff00]Weapon.AddExperience[/color], the final XP amount may depend on patch order.

Do not install this together with a fixed [color=#ffff00]Weapon Double XP[/color] mod unless you intentionally want the multipliers to stack.

[color=RoyalBlue][b]Uninstallation[/b][/color]

Remove the folder:

[code]BepInEx/plugins/WeaponXpMultiplier/[/code]
Optionally remove:

[code]BepInEx/config/kumo.sulfur.weapon_xp_multiplier.cfg[/code]
[color=RoyalBlue][b]SULFUR Config Localization Support[/b][/color]

This mod includes localization files for SULFUR Config.

This localization support is only for the in-game configuration page provided by SULFUR Config. It localizes the mod name, config sections, setting names, and setting descriptions shown in the config UI.

It does not change the game’s own text, item names, dialogue, or gameplay content.
